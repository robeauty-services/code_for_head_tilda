# code_for_head_tilda

Скрипти для `<head>` сторінок Тільди. Три сайти, три незалежні бандли з одного репо.

Критичне, щоб не забути:

- **Ніколи не push напряму в `main`.** Гілка → PR → squash-мердж. (CI зараз нема — `.github/workflows/ci.yml` не закомічений, тому PR ніхто не перевіряє автоматично.)
- Три бандли: `src/head.js` → `dist/head.min.js` (robeauty.me), `src/manera-head.js` → `dist/manera.min.js` (maneraparfum.com) і `src/pl-head.js` → `dist/pl.min.js` (pl.robeauty.me). Номери секцій у всіх трьох збігаються, щоб їх можна було діфати між собою; секція 8 є тільки в PL.
- `dist/` комітиться в репо — саме звідти jsDelivr роздає файл. Змінив `src/` — не збирай і не тегай руками: `npm run release:<site> <version>` робить збірку + перепін + коміт + PR, а після мерджу `npm run release:<site>` без версії ставить тег.
- `npm run pins` показує, на якому тезі кожен сайт і чи той тег узагалі існує — швидка перевірка, чи не розʼїхалось.
- Автоматичного деплою нема: останній крок — вручну вставити `tilda_head_without_scripts/*.html` у налаштування сайту на Тільді.
- **Ніколи не переміщуй уже випущений тег** — jsDelivr кешує `@tag` назавжди, зміни просто не доїдуть (або доїдуть частково, що гірше).
